# 🎮 critigames.com - Repositório do Website

Este repositório contém o código-fonte e todos os recursos necessários para o website **critigames.com**, uma plataforma dedicada a notícias, críticas e análises de jogos eletrônicos.

## 💻 Tecnologias e Estrutura

O projeto é baseado em desenvolvimento web front-end e utiliza a seguinte arquitetura:

| Pasta/Arquivo | Descrição |
| :--- | :--- |
| **`css/`** | Arquivos de estilos CSS customizados e principais do site. |
| **`js/`** | Scripts JavaScript para interatividade e funcionalidades dinâmicas. |
| **`img/`** | Todas as imagens, banners, ícones e assets gráficos do site. |
| **`pages/`** | Arquivos HTML para páginas específicas (ex: Sobre, Contato, Arquivo de Notícias). |
| **`Logotipos/`** | Versões e formatos do logotipo oficial do site. |
| **`bootstrap/...`** | Distribuição e arquivos de temas (Jekyll-theme-Cayman) do Bootstrap 5.1.3. |
| **`index.html`** | O arquivo principal (página inicial) do website. |
| **`_config.yml`** | Arquivo de configuração do Jekyll para o tema. |

## 📌 Principais Commits (Histórico)

O histórico do repositório mostra os estágios de desenvolvimento:

* **`Create README.md`:** Criação inicial do arquivo de documentação.
* **`Set theme jekyll-theme-cayman`:** Configuração do tema Jekyll/GitHub Pages.
* **`finalizando home`:** Implementação final do layout da página inicial.
* **`new version 2.2`:** Atualizações e refatoração de CSS e páginas.
* **`vambora`:** Commit de trabalho, relacionado a scripts JavaScript e logotipos.
